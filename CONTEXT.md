# Railway journey

OnTrack helps a rider choose a Taiwan Railway route and a train for a particular time.

## Language

**Station**:
A Taiwan Railway stopping place that can be selected as an origin or destination.

**Route**:
An ordered origin and destination station pair.

**Station choice**:
The rider's current route intent, including manual or location-derived origins, destination history, and station recommendations.
_Avoid_: Route selection state
